(2026-07-13) 컨트롤스탑 마감/오픈시간/구간 평균속도 규칙 추가 (현재 비활성화)
================================================================

[ 배경 ]
LV8 도입에도 불구하고, SOC 여유가 있는데 "벌어치기"(초반 며칠 태업하다
막판에 몰아붙이는) 전략이 여전히 통과되는 걸 발견 -> 실제 대회 규정과
비슷하게 일자별 체크포인트를 강제하기로 결정.

[ 추가한 3가지 규칙 ]
1) 일자별 마감: race.day_end_dist에 이미 있던 값(23일->CS2, 24일->CS4,
   25일->CS6, 26일->CS8, 27일->Finish)을 실제 마감으로 강제. 그날 안에
   목표 지점 못 넘으면 break(실격).
2) CS 오픈 시간: RaceConfig에 CS_open_hour 딕셔너리 신설(현재 전부 8시
   placeholder). 오픈 시간 전에 도착하면 오픈 시각까지 Accum_s를 밀어서
   대기 후 정차 시작.
3) 구간 평균속도: RaceConfig에 min_leg_avg_speed=60.0 신설. 직전 CS ~
   현재 CS 구간의 순수 주행 평균속도(정차 시간 제외)가 60km/h 미만이면
   실격.

[ 검증 ]
trial_2의 best 트라이얼(#158, SOC 58% 남기고 시간 마감 실패)로 테스트한
결과, 23일차 마감(631,000m)을 615,580m까지밖에 못 가서 15.4km 모자라게
실격되는 것 확인 -> 의도한 대로 "벌어치기" 패턴을 정확히 잡아냄.

[ 임시 비활성화 이유 ]
현재 best_params는 이 3가지 규칙이 없던 상태에서 탐색된 것이라, 규칙을
켜면 기존 best_params가 전부 실격 처리되어 app.py에서 "완주 실패"로
잘못 표시됨. 사용자가 지도 UI 작업에 먼저 집중하길 원해서, 세 로직
전부 Functions/Vehicle_Function.py에서 주석처리(# 임시 비활성화 표시)
해두고 실제 삭제는 안 함.
