(2026-07-12) pack.Cell이 전역 cell과 분리되어 있던 버그
================================================================

[ 문제 ]
app.py에서 "차량 제원 설정" 다이얼로그를 열고 배터리 셀 값(방전 용량,
전압 등)을 바꿔서 "적용"해도, 시뮬레이션 결과가 하나도 안 바뀜.
사용자 최초 증상 보고: "차량 제원 설정하면 바로 시뮬레이션이 끊어지는데"
-> 실제로는 별개의 두 가지 문제였음(아래 재확인 항목 참고).

[ 원인 ]
Configs/Vehicle_Params.py의 BatteryPack 데이터클래스:
    @dataclass
    class BatteryPack:
        HV_S: int = 40
        ...
        Cell: BatteryCell = field(default_factory=BatteryCell)  # 별도 사본!

        def __post_init__(self):
            self.HV_Energy = self.HV_S * self.HV_P * self.Cell.V_batt_nom * self.Cell.Capa_batt / 1000
            ...

pack.Cell이 전역에서 쓰는 `cell = BatteryCell()`과 완전히 다른 별도
인스턴스. app.py 다이얼로그가 편집하는 건 전역 cell인데, pack의 파생값
(HV_Energy, HV_Req 등)은 pack.Cell(수정 안 되는 사본) 기준으로 계산돼서
사용자가 뭘 바꾸든 반영이 안 됐음.

[ 해결 ]
Configs/Vehicle_Params.py 최하단에서:
    pack.Cell = cell        # pack 자체 Cell 대신 전역 cell 참조
    pack.__post_init__()    # 참조 변경에 맞춰 파생값 재계산
검증: cell.Capa_batt를 8000으로 바꾸고 pack.__post_init__() 재호출 시
pack.HV_Energy가 2592.0 -> 3456.0으로 정상 반영 확인.

[ 재확인: 원래 증상("설정하면 시뮬레이션이 끊어짐")의 진짜 원인 ]
이건 위 버그와 무관하게, Streamlit 자체의 동작 방식 때문이었음: 사용자가
상호작용(버튼 클릭)을 하면 Streamlit이 진행 중이던 스크립트 실행을
무조건 취소하고 처음부터 다시 실행함. 시뮬레이션이 도는 동안 화면에
떠 있던 "차량 제원 설정" 버튼을 누르면(값을 바꾸든 안 바꾸든) 진행 중
시뮬레이션이 취소되는 것.
해결: st.session_state.sim_running 플래그 + 2단계 rerun 패턴으로
시뮬레이션 도는 동안 다른 버튼들을 disabled 처리.

[ 관련 파일 ]
Configs/Vehicle_Params.py, app.py

[ 상태 ]
둘 다 해결 완료.
