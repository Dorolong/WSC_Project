[완료] 차량 제원 설정 계정 저장/불러오기 기능
================================================================
완료일: 2026-08-02

[ 배경 ]
progress/28(차량 제원 전역상태 격리 버그수정)의 후속. 세션별로 cfg를
격리하고 나니, 사용자가 "새로고침하면 설정값이 초기화되는 거야?"라고
질문 - 버그 수정으로 생긴 정상적인 부작용(예전엔 전역이라 우연히
계속 남아있었던 것)이지만, "마지막에 쓰던 설정을 불러오고 싶다"는
합리적인 요구라 계정 기반 저장/불러오기 기능을 추가하기로 함. 추가로
"내가 실행했던 기록 클릭하면 그때 설정도 불러오고 싶다"는 요청도
같이 반영.

[ DB 스키마 (사용자가 Supabase SQL Editor에서 직접 실행) ]
- 신규 `user_settings` 테이블: user_id(PK, auth.users FK),
  updated_at, vehicle_cfg(jsonb). RLS로 본인 행만 조회/저장/수정
  가능(`for all` 정책 하나로 select/insert/update 전부 커버).
- 기존 `simulation_runs` 테이블에 `vehicle_cfg`(jsonb) 컬럼 추가 -
  그 실행 때 사용한 차량 제원도 같이 기록.

[ 구현 - app.py ]
- **cfg_to_jsonable(cfg) / cfg_from_jsonable(data)**: cfg(physics/
  solar/cell/pack/power/drive/race 묶음, SimpleNamespace)를 Supabase
  jsonb 컬럼에 저장 가능한 dict로 직렬화/역직렬화.
  - `dataclasses.asdict()`로 선언된 필드만 추출 - `__post_init__()`이
    계산한 파생값(HV_Energy, v_max 등)은 dataclass field가 아니라서
    자동으로 안 들어감 - 저장 용량 절약 + 복원 시 재계산으로 항상
    최신 상태 보장.
  - numpy 배열(cell.ocv_soc/ocv_V)은 `.tolist()`로 변환(재귀 처리).
  - 복원 시 `build_default_cfg()`를 베이스로 값만 덮어써서, 저장 당시
    없던 필드(향후 추가되는 차량 제원 항목)가 있어도 기본값으로 안전
    하게 채워짐.
  - `pack.Cell`은 별도 복원 안 하고 `pack.HV_S/HV_P/LV_S/LV_P`만
    복원 후 `pack.__post_init__()` 재호출 - `build_default_cfg()`가
    이미 `pack.Cell = cell`(같은 인스턴스 참조)로 만들어두므로 자동
    으로 올바르게 연결됨.
- "차량 제원 설정" 다이얼로그: 기존 "적용" 버튼 옆에 **"적용 후
  계정에 저장"**(적용 로직 실행 + `user_settings`에 upsert),
  **"마지막 저장값 불러오기"**(user_settings에서 조회 후
  `st.session_state.cfg` 교체) 버튼 추가. 둘 다 비로그인 시
  disabled.
- "내 시뮬레이션 기록": 기존 `st.dataframe` 표시를 행별 루프 +
  "불러오기" 버튼(`st.button(key=f"load_run_{row['id']}")`)으로
  변경 - 버튼 누르면 그 기록의 `vehicle_cfg`를 `st.session_state.cfg`
  로 복원. 예전 기록(vehicle_cfg 컬럼 추가 전 저장분)은 값이 없어서
  안내 메시지만 표시.
- 시뮬레이션 실행 시 `st.session_state.last_vehicle_cfg`에 그 실행
  때 쓴 cfg를 스냅샷 저장(직렬화된 형태) - "결과 서버에 저장" 버튼이
  이 스냅샷을 `simulation_runs.vehicle_cfg`에 같이 기록(저장 시점의
  `st.session_state.cfg`가 아니라 실행 당시 값을 써야 정확함 - 그
  사이에 다이얼로그에서 설정을 또 바꿨을 수 있으므로).

[ 검증 ]
스크래치패드 테스트: mass/HV_S 등 값 변경 후 `cfg_to_jsonable()` ->
`json.dumps()`(에러 없음, numpy 등 비직렬화 객체 안 남음 확인) ->
`json.loads()` -> `cfg_from_jsonable()` round-trip. 값 일치, 파생값
(HV_Energy)이 새 HV_S 기준으로 정확히 재계산됨, ocv_V 배열 일치,
`pack.Cell is cell`(참조 관계 유지) 확인, race의 dict 필드
(Control_Stop_2025) 보존 확인, 빈 dict 입력 시 기본값 폴백 확인 -
전부 통과. py_compile 통과, 로컬 Streamlit 서버 정상 기동 확인.
