================================================================
웹 통합 / HTML 전환 Phase 2~6 구현 기록
================================================================
작성일: 2026-08-05

[배경]
progress/43 및 docs/codex_web_migration_tasks.txt에 정의된 Phase 2~6을
진행했다. Phase 0~1은 이미 main에 merge된 상태였고, 이번 작업은 단일
HTML/FastAPI 서버에서 시뮬레이션, 차량 제원, 부가 기능까지 동작시키는
것을 목표로 했다.

[구현]
1. Phase 2 - 시뮬레이션 API 백엔드
   - shared/cfg_serde.py 신설: cfg_to_jsonable/cfg_from_jsonable 공용화.
   - JSON round-trip 후 race dict 키가 문자열이 되는 문제를 발견해
     Control_Stop_2025/CS_open_hour/CS_close_hour 키를 int로 복원하도록
     수정했다.
   - server/sim_runner.py 신설: run_simulation()을 자식 프로세스에서 실행,
     progress/result/csv/figure JSON을 outputs/sim_runs/에 저장.
   - server/main.py에 /api/sim/runs, /api/sim/runs/{id}, /figure, /csv,
     /api/sim/route, /api/sim/default-config 추가.
   - WSC_MAX_SIM_CONCURRENT 추가, Optuna 큐와 시뮬레이션 큐 분리.
   - 시뮬레이션 CSV/figure 산출물은 사용자별 최근 5개 + 24h TTL 기준으로
     정리.

2. Phase 3 - 시뮬레이션 프론트엔드
   - server/static/index.html에 Simulator 탭, 진행률, route map, 결과 카드,
     Plotly 차트, CSV 다운로드를 추가.
   - simulator.js/charts.js/route-map.js 신설.
   - route-map.js는 기존 components/route_animator/index.html의 projection과
     path 렌더링 방식을 가져오되, 반복 애니메이션이 아니라 API 진행률을
     반영해 driven path를 갱신한다.

3. Phase 4 - 차량 제원 모달
   - vehicle-config.js 신설.
   - 서버의 /api/sim/default-config에서 기본 cfg를 받아 HTML dialog로 편집.
   - physics/solar/cell/pack/power/drive/race/simpara/OCV 섹션 제공.
   - Supabase user_settings 저장/불러오기 연결.

4. Phase 5 - 부가 기능
   - auxiliary.js 신설.
   - 릴리즈 노트, 튜토리얼, 코드 보기, simulation_runs/optuna_runs 기록 조회
     모달 추가.
   - HTML 시뮬레이션 결과를 기존 simulation_runs 테이블에 저장하는 버튼 추가.
   - release-notes.json 신설.

5. Phase 6 - 정리
   - README.md, SETUP.md, server/README.md를 새 HTML/FastAPI 통합 구조 기준으로
     갱신.
   - app.py는 사용자 최종 확인 전까지 legacy로 보관했다.

[검증 제한]
- 실제 Supabase 계정 로그인, user_settings 저장/불러오기, simulation_runs 저장,
  optuna_runs 조회는 테스트 계정/브라우저 세션이 없어 직접 확인하지 못했다.
- Playwright 패키지는 있었지만 브라우저 바이너리가 설치되어 있지 않아 실제
  화면 screenshot 검증은 수행하지 못했다. HTTP 정적 응답과 JS 모듈 import로
  대체했다.
- Oracle 서버 systemd 배포/재시작은 아직 수행하지 않았다.
