================================================================
환경 설정 및 경로 수정
================================================================

[ 문제 ]
시스템 기본 Python이 3.7.8이라 optuna(4.0.0+), 최신 streamlit(1.37+, st.dialog
필요) 설치가 안 됨. __pycache__에 cpython-312 흔적은 있는데 정작 이 PC엔
Python 3.12가 없는 상태였음.

[ 해결 ]
- winget으로 Python 3.12.10 설치
- 프로젝트 루트에 .venv 가상환경 생성 (py -3.12 -m venv .venv)
- requirements.txt를 pip freeze 기준으로 전체 의존성 버전 고정
  (numpy, pandas, matplotlib만 있던 것에서 optuna, streamlit, plotly,
  requests 등 실제 쓰는 패키지 전부 포함하도록 갱신)
- SETUP.md 신규 작성: 다른 컴퓨터로 옮길 때 재현 방법
  (venv 자체를 옮기지 않고, requirements.txt로 새로 구성)

[ 하드코딩된 절대경로 수정 ]
- scripts/main.py: Optuna_result.csv 저장 경로가
  "C:\Users\Owner\Desktop\..." (존재하지 않는 사용자 경로)로 박혀있던 것
  -> "outputs/Optuna_result.csv" 상대경로로 수정
- Environment/Open_Meteo_API.py: TRACK.csv 읽기, env_data.csv 저장 경로
  둘 다 같은 문제 -> 상대경로로 수정
- 공통 전제: 프로젝트 루트에서 실행한다는 조건으로 통일

[ 상태 ]
완료. 이후 모든 실행은 .venv 기준으로 진행.
