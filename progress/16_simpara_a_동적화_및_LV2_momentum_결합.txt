[완료] simpara.a 동적 변수화 + LV2 momentum 결합
================================================================
완료일: 2026-07-20 (백로그 3번 항목, 2026-07-18에 계획만 세워둠)

[ 배경 ]
기존엔 cal_drive_res()의 F_acc = physics.mass * a에서 a가
simpara.a(고정 상수 0.0)라, 실제 가감속에 따른 관성/운동에너지
효과가 시뮬레이션에 전혀 반영 안 됐음. LV2 slope look-ahead와
직접 연결되는 문제로, a가 고정이면 "언덕 전에 미리 가속해서
관성으로 넘는다"는 효과가 모델에 없음.

[ 1. a 계산 ]
cal_drive_res(step, dt, ...) 안에서 a = (v-prev_v)/dt로 매 스텝
실제 속도 변화 기반 계산(dt<=0 방어 포함, progress/15 9번 참고).
cal_drive_res가 P_batt와 함께 a도 리턴하도록 시그니처 확장 -
사용자 제안으로 "회귀적으로 다시 구하지 말고 이미 힘 계산에 쓴
a를 그대로 내보내자"는 방향.

[ 2. carry-over 배관 ]
step["a"]는 cal_drive_res가 계산하는 시점이 mpc_speed() 호출보다
뒤라 이번 스텝엔 못 쓰고 다음 스텝에만 반영 가능. prev_a bare
변수를 만들어 compute_vehicle_energy() 호출 직후
prev_a = step["a"]로 갱신, 다음 iteration의 step 생성 시
a=prev_a로 시딩(다른 carry-over 변수들과 동일 패턴).
Configs/Vehicle_Params.py의 simpara.a도 simpara.prev_a로 개명해서
run_simulation()의 bare 변수명과 1:1 대응시킴.

[ 3. momentum 물리적 타당성 논의 ]
"언덕 전에 가속 -> 관성으로 넘기기" 전략이 이 모델에서 실제로
SOC를 아끼는지 구현 전에 먼저 검토:
- F_slope/F_acc의 거리 적분은 고정된 시작/끝 속도·고도차에서는
  경로(속도 프로파일)와 무관 - momentum 자체가 공짜는 아님.
- F_aero ~ v^2(볼록함수)라 같은 평균속도(=같은 소요시간)면 균일한
  속도가 오히려 aero 손실이 최소(Jensen 부등식) - 속도를 들쭉날쭉
  하게 가져가는 건 그 자체로 약간의 손해.
- 결정적으로, **회생제동 효율(Regen_eff=0.6)이 40% 손실**이라
  "가속 후 회생으로 감속"하는 형태의 momentum은 순손실. 반대로
  "내리막에서 회생 없이 자연 가속 -> 그 운동에너지로 다음 평지/
  오르막에서 모터 출력을 덜 쓰는" 형태(PE->KE 직접 전환, 손실 거의
  없음)는 PE->전기(회생 60%)->다시 모터 방전 경로보다 변환 손실이
  한 번 덜 끼어 유리함이 명확.
- 결론: 이론적으로 완전한 최적 여부는 언덕 형상/차량 스펙에 따라
  달라 단정 어려움(진짜 최적화하려면 Pontryagin 최소원리/동적계획법
  수준의 최적제어 문제) - 실용적으로는 회생 없는 자연 감속/가속을
  허용하는 방향으로 구현하고 Optuna로 A/B 검증하기로 함.

[ 4. mpc_speed() LV2 반영 ]
slope_ahead > 임계값(오르막)일 때만 a 기반 페널티 완화 적용,
경계에서 값이 뚝 끊기지 않도록 하드 if 대신 스무스 램프 사용
(LV8 하드스위치 버그 교훈 반영 - debug_logs/(2026-07-13)_LV8_시간예산_설계.txt):
    slope_severity = clip((slope_ahead - 0.02) / 0.02, 0, 1)
    momentum = clip(a * momentum_gain, 0, 1) * slope_severity
    v -= slope_k * slope_ahead * (1 - momentum)
momentum_gain을 mpc_default_params에 신규 추가(기본값 1.0, 아직
Optuna 탐색공간엔 미포함).

[ 상태 ]
구현 완료, Optuna 트라이얼이 에러 없이 도는 것까지 확인. **실제
SOC 개선 효과는 아직 A/B로 검증 안 됨** - Optuna 재탐색 시
momentum_gain을 탐색공간에 넣을지, 혹은 0 vs 현재값 비교로 효과만
먼저 확인할지는 progress/18(백로그) 참고해서 판단 필요.
