================================================================
[완료] mpc_controller.py simpara 전역 참조 제거
================================================================
완료일: 2026-08-05

[ 배경 ]
사용자가 "현재 mpc_controller의 가장 큰 문제가 뭐라고 생각해?"라고
물었고, 코드 검토 중 mpc_speed() 마지막 속도 변화량 댐퍼가
세션별 cfg가 아니라 Configs.Vehicle_Params의 전역 simpara를 직접
참조하는 문제를 확인했다.

룰베이스 기반 MPC를 먼저 개발한 뒤 각 규칙 항을 비용함수로 대체하는
사용자 계획은 유지하기로 했다. 이번 작업은 그 전환과 별개로,
현재 룰베이스 컨트롤러가 세션별 설정을 정확히 읽게 만드는 정합성
수정이다.

[ 구현 ]
1. Functions/Vehicle_Function.py
   - run_simulation() 내부 const dict에 `simpara = simpara` 추가.
   - 기존 cfg에서 꺼낸 세션별 simpara 인스턴스를 mpc_speed()까지
     전달하도록 배관을 연결했다.

2. mpc/mpc_controller.py
   - `from Configs.Vehicle_Params import *` 제거.
   - mpc_speed() 상단에서 `simpara = const["simpara"]`를 꺼내 쓰도록
     수정.
   - 마지막 속도 변화량 제한식의 `simpara.max_v_delta`가 이제
     모듈 전역이 아니라 현재 시뮬레이션 cfg 값을 따른다.

[ 버그 ]
- 수정 전: app.py의 "시뮬레이션 설정" 탭에서 매 스텝 최대 속도
  변화량(max_v_delta)을 바꿔도 mpc_speed()의 댐퍼에는 반영되지 않을
  수 있었다.
- 수정 후: run_simulation(cfg) -> const["simpara"] -> mpc_speed()로
  같은 cfg 인스턴스가 전달된다.

[ 검증 ]
- `rg`로 mpc_controller.py의 Configs.Vehicle_Params star import가
  제거된 것을 확인했다.
- `python -m py_compile`은 작성 당시 PowerShell에서 python 명령이 없고,
  `py -m py_compile`도 "No installed Python found!"로 실패해 실행하지
  못했다. 코드 변경은 import 제거와 dict 전달 추가에 한정된다.

[ 추가 검증 (2026-08-05, Claude 세션에서 실행) ]
위에서 못 했던 실행 검증을 별도로 마쳤다.
1. `py_compile` 통과 (mpc_controller.py, Vehicle_Function.py,
   scripts/main.py, app.py 전부).
2. star import 제거로 정의가 사라진 이름이 없는지 AST로 정적 확인 ->
   mpc_controller.py에 미정의 이름 없음.
3. **실제 전 구간 시뮬레이션 2회 비교** (동일 파라미터, cfg만 다르게):
   - max_v_delta=2 -> 도달 2,833,560m / 평균 76.61km/h
   - max_v_delta=8 -> 도달 2,833,700m / 평균 76.56km/h
   속도 프로파일이 서로 달라지는 것을 확인 -> 세션 설정이 실제로
   댐퍼에 반영됨(수정 전에는 무시됐던 부분).
   같은 테스트에서 모듈 전역 `VP.simpara.max_v_delta`가 그대로 유지되는
   것(전역 오염 없음)과 두 cfg가 서로 격리되는 것도 함께 확인.
   (두 실행 모두 종료 사유는 "27일 제한기간 초과" - 이건 이번 수정과
   무관한 기존 파라미터 상태의 결과이고, 검증 목적은 "설정 반영 여부"
   였으므로 문제 없음.)

[ 상태 ]
완료. LV4 에너지 예산 문제는 유지한다. 현재 합의된 방향은 룰베이스
building block을 먼저 완성하고, 이후 같은 항들을 비용함수/solver 기반
MPC로 재구성하는 것이다.
