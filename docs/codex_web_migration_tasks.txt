**각 Phase는 아래 5단계를 순서대로 거친다. 건너뛰지 말 것.**

  (1) 설계

        - 만들/고칠 파일 목록과 각 파일에서 할 일
        - 기존 코드와 맞물리는 지점(함수명·줄번호)
        - 판단이 갈린 부분과 선택한 이유
        - 이 Phase에서 깨질 수 있는 기존 기능
      **설계 없이 코드부터 쓰지 말 것.**

  (2) 설계 검증 (게이트 A)
      아래를 스스로 점검하고, 하나라도 걸리면 구현에 들어가지 말고
      보고한다:
        - 금지 1~4를 위반하는 부분이 있는가?
        - 해당 Phase의 "선결 조건"이 충족됐는가?
        - 지시서에 적힌 줄번호/함수명이 실제 코드와 맞는가?
          (**어긋나면 지시서가 낡은 것이니 실제 코드를 기준으로
          하고, 어긋난 사실을 보고할 것**)
        - 기존 기능을 깨뜨리는 변경이 포함돼 있는가?

  (3) 구현
      설계한 범위만 구현한다. 구현 중 설계를 바꿔야 하면,
      바꾼 내용과 이유를 보고서에 남긴다.

  (4) 검증 (게이트 B)
      해당 Phase의 "검증 조건"을 **전부** 수행한다.
      - 실행한 명령과 그 출력을 그대로 기록할 것
      - 환경 제약으로 못 한 항목은 **못 했다고 명시**할 것.
        추측으로 "정상 동작할 것으로 보임"이라고 쓰지 말 것.
      - 하나라도 실패하면 다음 Phase로 넘어가지 말 것.

  (5) 보고
      아래 6번 형식으로 보고하고, **사용자 확인을 받은 뒤**
      다음 Phase로 넘어간다. 확인 없이 연속 진행 금지.

**합칠 "다른 HTML 웹"에 대한 확정 사항 (2026-08-05):**
  이 레포에 없는 별개 사이트다(server/static/index.html이 아님).
    a) 스택: HTML + CSS + JavaScript + FastAPI 백엔드.
       빌드 도구/프레임워크 없음 - 이 지시서의 구조와 동일.
    b) **도메인: 오라클 서버와 같은 도메인. 인증은 Supabase 유지.**
       -> **CORS는 비이슈(same-origin).** 프리플라이트가 안 뜬다.
          오히려 server/main.py의 allow_origins=["*"]를 좁히거나
          제거할 것 - 지금은 아무 사이트나 이 API를 호출할 수 있다.
       -> 교차 도메인 토큰 문제 없음. 기존 localStorage 방식 유지.
    c) 합치는 방식: **그 사이트의 디자인 시스템을 가져오고, 오라클
       서버가 시뮬레이터와 Optuna 둘 다 서빙한다.** 외부 사이트가
       오라클로 이사 오는 게 아니라 디자인만 가져온다.
    d) **CSS 토큰/레이아웃은 현재 Streamlit과 최대한 비슷하게.**

  - **레이아웃·정보 구조·화면 흐름 = 현재 Streamlit과 유사하게.**

**[해소됨] 디자인 자산 미확보 -> "임의 구성 후 수정" 방식으로 진행**

  만들고, 나중에 실제 자산이 오면 토큰만 갈아끼운다.**

  ** 이 방식이 성립하려면 아래 규칙을 반드시 지켜야 한다 (중요) **

   T-1. **색·폰트·간격·radius·그림자는 전부 static/css/tokens.css의

   T-3. 토큰 이름은 용도 기반으로 지을 것(--color-primary,

           --mint          #E3F0E8    --paper         #F6F7F2
           --card          #FFFFFF    --line          #E3E1D8

           -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif
        **간격/radius/그림자 토큰은 아직 없으므로 새로 정의할 것**
        (기존 파일에 흩어진 px 값들을 --space-*, --radius-* 로 승격).
   T-5. **차트 색은 tokens.css에 넣지 말 것.** Plotly figure를
        서버(Python)에서 만들어 JSON으로 내려주는 구조라 차트 색은
        Python 쪽에 있다(app.py의 steelblue/tomato/orange/
        mediumpurple/seagreen 등). CSS와 이중 관리하지 말 것.
